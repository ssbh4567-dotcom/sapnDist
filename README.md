# sapnDist

## Overview

`sapnDist` provides mathematical functions and statistical procedures for the Smooth Additive-Perturbed Normal (SAPN) distribution. The package implements the SAPN distribution together with parameter estimation, confidence intervals, shape measures, and a parametric bootstrap Anderson-Darling goodness-of-fit procedure.

The package provides the standard density, cumulative distribution, quantile, and random-generation functions, along with estimation by the Method of Moments (MME) and Maximum Likelihood Estimation (MLE).

## Installation

The development version of `sapnDist` can be installed from GitHub using the `remotes` package:

```r
install.packages("remotes")
library(remotes)

install_github("ssbh4567-dotcom/sapnDist", force = TRUE)
library(sapnDist)
```

## SAPN Distribution

The Smooth Additive-Perturbed Normal (SAPN) distribution is parameterized by the location parameter `mu`, scale parameter `sigma`, perturbation parameter `alpha`, perturbation location parameter `c`, and the steepness parameter `k` of the sigmoid perturbation. The default value of `k` is 2, with

```math
\sigma > 0, \qquad 0 < \alpha \leq 2.
```

The SAPN density is

```math
f(x;\mu,\sigma,\alpha,c,k)
=
\frac{2}{2+\alpha}
\left[
\phi(x;\mu,\sigma)
+
\frac{\alpha}{\sigma^2}
\phi(x;c,\sigma)(x-c)^2
\left\{1+\exp\left[-k\left(\frac{x-c}{\sigma}\right)\right]\right\}^{-1}
\right],
```

where `\phi(x;\mu,\sigma)` denotes the normal density with mean `\mu` and standard deviation `\sigma`.

## Distribution Functions

`sapnDist` provides the standard distribution functions for the SAPN distribution.

### Density

```r
dsapn(x, mu, sigma, alpha, c, k = 2)
```

Example:

```r
dsapn(0, mu = 0, sigma = 1, alpha = 0.5, c = 2)
```

### Cumulative Distribution Function

```r
psapn(q, mu, sigma, alpha, c, k = 2)
```

Example:

```r
psapn(1, mu = 0, sigma = 1, alpha = 0.5, c = 2)
```

The cumulative distribution function is obtained by numerical integration of `dsapn()`.

### Quantile Function

```r
qsapn(
  p,
  mu,
  sigma,
  alpha,
  c,
  k = 2,
  grid_width = 100,
  n_grid = 5000
)
```

Example:

```r
qsapn(0.5, mu = 0, sigma = 1, alpha = 0.5, c = 2)
```

The quantile function is obtained using a monotone Hermite spline approximation to the inverse CDF. The default values are `grid_width = 100` and `n_grid = 5000`.

### Random Generation

```r
rsapn(
  n,
  mu,
  sigma,
  alpha,
  c,
  k = 2,
  grid_width = 100,
  n_grid = 5000
)
```

Example:

```r
rsapn(10, mu = 0, sigma = 1, alpha = 0.5, c = 2)
```

Random observations are generated by inversion using the numerical inverse CDF.

## Parameter Estimation

The examples below generate data directly from the SAPN distribution with known parameters, so that the estimators can be checked against the true values.

### Maximum Likelihood Estimation

The function `fit_sapn_mle()` fits the SAPN distribution by maximum likelihood using a multi-start L-BFGS-B optimization with the exact analytical gradient.

```r
# Generate data from a known SAPN distribution
set.seed(42)
x <- rsapn(200, mu = 0, sigma = 1, alpha = 0.8, c = 2)

mle_fit <- fit_sapn_mle(
  x,
  k = 2,
  n_starts = 100,
  seed = 123,
  hessian = TRUE
)

mle_fit$estimate
# should lie close to mu = 0, sigma = 1, alpha = 0.8, c = 2
```

The function returns the fitted parameter vector

```math
(\hat{\mu},\hat{\sigma},\hat{\alpha},\hat{c})
```

together with the attained log-likelihood.

The arguments are:

- `x`: vector of observed data;
- `k`: steepness parameter of the sigmoid perturbation;
- `n_starts`: number of random starting values used in the multi-start optimization;
- `seed`: random number generator seed for reproducibility of the starting values; and
- `hessian`: logical argument indicating whether the observed Fisher information matrix is computed at convergence.

The Hessian is required for obtaining confidence intervals using `confint()`.

### Method of Moments

The function `fit_sapn_mme()` fits the SAPN distribution by the Method of Moments using a multi-start Nelder-Mead optimization.

```r
# Reuse the same SAPN-generated data
mme_fit <- fit_sapn_mme(
  x,
  k = 2,
  n_starts = 100,
  seed = 123
)

mme_fit$estimate
# should also lie close to mu = 0, sigma = 1, alpha = 0.8, c = 2
```

The function returns the fitted parameter vector together with the attained moment-matching loss. The arguments `k`, `n_starts`, and `seed` have the same interpretation as in `fit_sapn_mle()`.

## Confidence Intervals

The function `confint()` computes Wald and log-scale confidence intervals for the fitted MLE parameters.

```r
confint(
  mle_fit,
  parm = c("mu", "sigma", "alpha", "c"),
  level = 0.95
)
# the true values mu = 0, sigma = 1, alpha = 0.8, c = 2
# should fall within the reported intervals
```

Here, `parm` specifies the fitted parameters for which confidence intervals are obtained, and `level` denotes the confidence level. The fitted MLE must be obtained with `hessian = TRUE`.

When the fitted `alpha` falls below $10^{-4}$, i.e., close to the boundary `alpha = 0`, the parameter `c` may become weakly identifiable and the observed Fisher information matrix may be nearly singular. The package issues a warning in this situation, and the resulting confidence intervals should be interpreted with caution.

## Shape Measures

The function `sapn_shape()` computes the theoretical skewness and excess kurtosis corresponding to a given parameter vector.

```r
sapn_shape(
  mu = mle_fit$estimate["mu"],
  sigma = mle_fit$estimate["sigma"],
  alpha = mle_fit$estimate["alpha"],
  c = mle_fit$estimate["c"],
  k = 2
)
```

The function returns the theoretical skewness and excess kurtosis for the specified parameter values.

## Goodness-of-Fit Test

The function `gof_sapn()` performs the parametric bootstrap Anderson-Darling goodness-of-fit test for a fitted SAPN distribution.

```r
gof_sapn(
  x,
  mle_fit,
  B = 500,
  seed = 123,
  n_starts_boot = 50
)
# since x was generated from the fitted SAPN model, the test
# should not reject at conventional significance levels
```

The procedure computes the observed Anderson-Darling statistic, generates bootstrap samples from the fitted SAPN distribution, refits the model to each bootstrap sample using the same estimation method, and obtains the bootstrap p-value.

The main arguments are:

- `x`: observed data vector;
- `fit`: fitted SAPN model obtained from `fit_sapn_mme()` or `fit_sapn_mle()`;
- `B`: number of parametric bootstrap replications;
- `seed`: random number generator seed for reproducibility; and
- `n_starts_boot`: number of multi-start restarts used when re-estimating the parameters for each bootstrap sample.

The returned object contains the observed Anderson-Darling statistic, the bootstrap p-value, the number of successful bootstrap replications, and the estimation method.

For greater accuracy of the bootstrap p-value, larger values of `B` and `n_starts_boot` may be used. Increasing `B` increases the number of bootstrap replications and therefore the computational time. Increasing `n_starts_boot` increases the number of multi-start optimization runs for each bootstrap sample and also increases the computational time. Smaller values can be used for quick exploratory analyses, whereas larger values are preferable when more accurate bootstrap inference is desired.

## Complete Example

```r
# Install and load sapnDist
install.packages("remotes")
library(remotes)

install_github("ssbh4567-dotcom/sapnDist", force = TRUE)
library(sapnDist)

# Generate data from a known SAPN distribution
set.seed(42)
x <- rsapn(200, mu = 0, sigma = 1, alpha = 0.8, c = 2)

# Fit the SAPN distribution to data
mle_fit <- fit_sapn_mle(
  x,
  k = 2,
  n_starts = 100,
  seed = 123,
  hessian = TRUE
)

mme_fit <- fit_sapn_mme(
  x,
  k = 2,
  n_starts = 100,
  seed = 123
)

# Wald and log-scale confidence intervals for the MLE
confint(
  mle_fit,
  parm = c("mu", "sigma", "alpha", "c"),
  level = 0.95
)

# Theoretical skewness and excess kurtosis
sapn_shape(
  mu = mle_fit$estimate["mu"],
  sigma = mle_fit$estimate["sigma"],
  alpha = mle_fit$estimate["alpha"],
  c = mle_fit$estimate["c"],
  k = 2
)

# Parametric bootstrap Anderson-Darling goodness-of-fit test
# Smaller values are used here for a quicker example
gof_sapn(
  x,
  mle_fit,
  B = 50,
  seed = 123,
  n_starts_boot = 20
)
```

## Reproducibility

The `seed` argument in `fit_sapn_mle()` and `fit_sapn_mme()` controls the random starting values used in the multi-start optimization. In `gof_sapn()`, a single `seed` argument controls both the bootstrap sampling and the multi-start grids used in every refit, via one call to `set.seed()` at the start of the procedure. Specifying the same seeds and optimization settings facilitates reproducibility of the numerical results.
